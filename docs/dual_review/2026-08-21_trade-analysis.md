# 매매분석 재구현(#2) — A/B 리뷰 (2026-08-21, v0.19.0)

실제 체결이력으로 진입→청산 자동추적 + 강/약 인사이트. 리뷰가 잡은 핵심은 '진입강도 enrichment 오염'.

| # | 발견 | 심각도 | 최종 |
|---|------|--------|------|
| H1 | **enrichment가 mode 필터·시간창 없이 종목+가격만으로 매칭** → DRY_RUN 기본이라 페이퍼(dryrun) 스냅샷이 강/약 인사이트를 좌우(근거 없는 헤드라인) | HIGH | **FIX**: 실거래(mode==="real")·근거(!dryRun)만 사용 + **1:1 소비**(중복 카운트 방지). 실주문 전엔 진입강도 안 붙음(정직) |
| M1 | 첫매치·중복 미제거로 강/약 표본 부풀림 | MEDIUM | **FIX**: usedTrade/usedRat Set으로 1:1 |
| M2 | 400일 조회로 리포트 60초 캐시 무력화·429 위험 | MEDIUM | **FIX**: 리포트와 동일 75일 바닥(옛 매매는 저장본 누적으로 커버) |
| L1 | win(pnl≥0)과 %색(pnlClass(pct)) 불일치 → +% 인데 빨강 행 가능 | LOW | **FIX**: 수익률·손익 색을 win(실제 손익) 기준 통일 |
| L2 | 스케일인 포지션은 가장 이른 lot 기준이라 보유기간 과대 | INFO | 수용(코드 주석). |

**리뷰가 확인한 정상:** buyAtMs ≤ sellAtMs 보장(정렬상 소비 lot은 항상 이전) → 음수 보유 없음, Math.max(0)은 방어. 
insights 나눗셈 가드·반올림·헤드라인 임계(각 3건+·차이 5%↑) 정상. source/none 로직 report()와 일치. 
제거코드(trades/tradeStats/refreshTrades/closeTrade/deleteTrade/fmtStr) 잔여참조 없음(죽은 IPC는 무해).

**검증:** 실체결 주입 → 사이클·요약·보유기간·손익색(win기준) 정상, 진입강도는 real 기록만이라 '—'(정직). 
vitest 263개(분석 10개), 타입체크(web+app) 통과. 라이브 넘침0·콘솔0.

오너 지시: "탐색의 정확한 스크리닝 기능 구현 — 필터 사용자 조절 + 걸린/탈락 이유 명확화."

## 변경 요약
- `scanScreener(bodyRatio, count)` → 옵션 객체 `scanScreener({bodyRatio, count, priceMin, priceMax})`. IPC 4곳(main/preload/web adapter/d.ts) 갱신.
- 가격대($1~$9 고정)·스캔 종목수(60 고정) → **사용자 조절**(10~200, 가격 하한/상한). `ScreenRun`에 priceMin/priceMax 추가.
- **'아쉽게 탈락(근접)' 목록** 신설 — none 중 하드게이트 2개 이상 통과 종목을 **왜 빠졌는지 사유와 함께** 표시.

### A/B가 "깨보려다 실패"로 확인한 것(정상)
- `none` 종목의 evidence는 항상 non-null(insufficient만 null이고 근접 목록서 제외) → 빈 사유·"패턴 미완성" 폴백은 **도달 안 함**(안전).
- 입력 파싱(toNum): 빈칸·문자·음수·거대값·하한>상한 전부 방어(UI + 엔진 이중 클램프). NaN 렌더 없음.
- IPC 위치인자 잔존 없음(4곳+테스트 전부 옵션 객체로 이전). 후보/근접/insufficient 중복·누락 없음.

## #5 문구 — 전 → 후 (주요)

### 상단바·전역
- `🔒 주문 잠금 (드라이런)` → `🔒 주문 잠금 (연습만)` (+ title 평이화)
- `⭘ 킬 스위치` → `🛑 전체 주문잠금`; 확인창 `킬 스위치를 켭니다` → `🛑 전체 주문잠금(비상 정지)을 켭니다 …`
- `🔲 1컬럼 / 🔳 2컬럼` → `🔲 한 화면 / 🔳 두 화면`
- `⚠ 마감 1분 전: 정정·취소 불가 구간` → `… 지금은 주문 정정·취소가 안 돼요`

### 계산기
- 기법 재료 hint: `전봉종가~EMA200을 3등분…` → `직전에 마감된 봉의 종가와 EMA200(가격 200개의 평균을 이은 선) 사이를 3등분…`
- `진입 = 벽 + 1틱. 벽 판단은 사람 몫` → `매수벽(사려는 주문이 두껍게 쌓인 가격)보다 한 칸(1틱) 위에서 삽니다…`
- 주문 버튼: `진입 지정가` → `매수만 (지정가)` · `진입+익절(OTO)` → `매수+익절 자동` · `조건주문(익절+손절)` → `익절+손절 걸기`
- 환율 `매매기준율·참고용` → `참고용`; `1 USD =` → `1달러 =`
- 표 헤더 `투입액` → `드는 돈`; 저장 title `3개 타점` → `1·2·3차 매수가`

### 탐색(스크리너)
- 긴 ①~⑤ 전문용어 문단 → **단계별 줄바꿈 + 첫 등장 쉬운 풀이**(EMA200·이치모쿠 구름·하이킨아시·도지). h2 부제 `거래량 상위 60종목 스캔` → `거래량 많은 종목에서 매수 후보 자동 찾기`
- `음봉 도지 몸통비율 상한` → `도지로 인정할 몸통 크기 상한`; 표헤더 `구름top/세션고점` → `구름 위/장중 고점`; `하드게이트` → 툴팁 평이화

### 체결강도·매매분석
- h2 `(매수체결량 ÷ 매도체결량 × 100)` → `(사려는 힘 vs 팔려는 힘)` + 본문 쉬운 풀이(틱룰·시계열 제거)
- 스캘핑/다이버전스 문단 → 쉬운 말(“가격은 더 내렸는데 체결강도는 오히려 오르면…”)
- 매매분석 부제/본문 평이화, `홈 PC` → `집 PC`(+폰이면 [폰에서 쓰기])

### 주문현황
- 조건주문 종류 칩 `OTO/OCO`(원문) → `condTypeKo()`로 `매수→익절 / 익절+손절`(툴팁에 원문 유지)
- 조건주문 h2에 `감시가/지정가` 뜻 한 줄 추가
- `유형 … DAY` → `… 당일만`; 조건주문 유형 `LIMIT` → `지정가/시장가`
- 조건주문 취소 버튼 `삭제` → `취소`(일반주문과 일치); 취소 실패 `alert(String(e))` → `취소하지 못했어요: …`

### 각종 모달·리포트
- OCO 편집 모달 제목 `조건주문(익절+손절)` → `익절+손절 걸기`; “앱은 막지 않고” 개발자투 문장 평이화
- 근거보기 `진입+익절(OTO)` → `매수+익절 자동`, `(모의)` → `(연습)`
- 주문확인 `모의 전송(기록만)` → `연습으로 보내기(기록만)`, `주문 잠금(드라이런)` → `주문 잠금(연습)`
- 리포트 히어로 `실현 손익` → `손익 (실제로 판 것만)`; 빈상태/출처 `홈 PC` → `집 PC`, `정리된 거래` → `판 거래`

## A/B 리뷰 결과 및 반영

리뷰 방식: 리뷰어 A(총괄 정합성) + 리뷰어 B(적대적 회귀 헌팅) 병렬. 둘 다 diff 전체 + 실제 파일 교차 확인. **HIGH 1건 · MEDIUM 다수 · LOW 소수** 지적, 전부 반영.

### 리뷰어 A(총괄) — HIGH 0
구조·기능·안전 문구 **무결**(6그룹 누락 0, 핸들러 보존, JSX 균형, saveSettings 묶음 정합, 안전문구 오히려 강화, 기술 설명 사실 부합). MEDIUM은 **용어 반쪽 개명**:
- (A-M1) 계산기 시드박스에 "시드" 잔존(1760/1763/1785)·저장 토스트 "시드 설정"(1391) → **매수비율/기준금액으로 통일** ✅
- (A-M2) OTO 라벨 두 갈래(버튼 "매수+익절 자동" vs 칩 "매수→익절") → **condTypeKo OTO를 "매수+익절"로 통일** ✅
- (A-M3) 버튼은 새 이름인데 주문확인 팝업 제목 3개(824/854/920)는 옛 이름(+"OTO" 재노출) → **제목을 "매수만 (지정가)/매수+익절 자동/익절+손절 걸기"로 교체** ✅
- (A-L1) EMA를 "평균선"으로 단순화 → 초보용 허용범위로 **유지**(엄밀히 SMA 뉘앙스지만 혼동 방지 우선).

### 리뷰어 B(적대) — HIGH 1
- **(B-H1, HIGH) 카드 분리가 유발한 피드백 회귀**: `savedMsg`가 ② 토스 연결 카드(2714)에서만 렌더 → ⑤(손익비·매수비율·한도) 저장 버튼을 눌러도 확인/에러 문구가 스크롤 위 다른 카드에 조용히 떠 안 보임(특히 손익비 검증 에러). → **⑤ 각 저장 버튼 옆에 `savedMsg` 표시 추가**(에러는 err, 성공은 ok 클래스). ✅
- (B-M1) 주문확인 팝업 제목/본문 옛 이름 → 제목은 A-M3에서 해결, 본문 `당일(DAY)` → **"당일만 — 오늘 안 체결되면 자동 취소"** ✅
- (B-M2) 시드 반쪽 개명 → A-M1과 동일, 해결 ✅
- (B-M3) "주문 잠금"(드라이런 배지) vs "전체 주문잠금"(킬 버튼) 단어 겹쳐 혼동 → **킬 스위치를 "🛑 비상 정지 / 🔴 비상 정지 중"으로 분리**(확인창도 "비상 정지를 켭니다"). ✅
- (B-L1) condTypeKo 툴팁이 `c.type=null`에서 "…: null" 노출 → **`${c.type ?? "조건주문"}`으로 가드** ✅. timeInForce=GTC 등 희귀 원시값 노출은 데이마켓 실무영향 미미 → 유지.

B가 의심 후 기각한 6건(JSX 파손·폰카드 웹노출·컨트롤 유실/중복·leg 라벨 매핑·disabled 조건·DAY 매핑)은 모두 문제 없음으로 확인.

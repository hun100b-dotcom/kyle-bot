# 카일 매매도구 사용법 (v0.2)

> 대상: 처음 쓰는 사람 기준. 용어는 괄호로 풀어서 설명합니다.
> v0.1(자율 봇)과 다릅니다 — v0.2는 **오너 결정으로 "수동 계산기 + 주문 도구"로 전환**됐습니다.

## 1. 이 도구는 무엇인가

- **알아서 매매하지 않습니다.** 계산·조회·주문 전부 당신이 버튼을 눌러야 한 번 실행됩니다.
- 카일매매기법 3종(삼분할·호가창·캔들)의 **진입가·익절가·손절가를 계산**해 달러·원화로 보여주고,
- 그 값으로 **토스에 주문(지정가/조건주문)** 을 넣을 수 있습니다.
- 익절/손절 감시는 **토스 서버의 조건주문(OCO)** 이 하므로 **앱을 꺼도 작동**합니다.
- **⚠ v0.2는 실서버 주문이 잠겨 있습니다(드라이런).** 어떤 조작으로도 실제 주문은 나가지 않고
  "모의 기록"만 남습니다. 해금은 소액(1주) 테스트를 당신이 직접 통과시킨 뒤 별도 버전에서.

## 2. 설치

`release/KyleBot-0.2.0-arm64.dmg` 더블클릭 → KyleBot을 응용 프로그램으로 드래그 → 실행.
(경고가 뜨면 우클릭 → 열기. 개인용 무서명 앱이라 그렇습니다.)

## 3. 기본 흐름 (계산기 탭)

1. **종목 입력 → [시세·환율 조회]** — 현재가와 환율(1 USD = ₩?)이 표시됩니다.
   - 환율은 토스 공식 API(1분 갱신, 참고용)에서 자동으로 가져옵니다. 실패하면 수동 입력 칸이 나타납니다.
2. **매매기법 선택** — 그때그때 직접 고릅니다:
   | 기법 | 입력할 재료 | 계산 규칙 |
   |------|------------|-----------|
   | 삼분할 | 전봉 종가, EMA200 | 구간 3등분 → 1·2·3분할 (전봉종가>EMA200 필수) |
   | 호가창 | 매수벽 가격 | 진입 = 벽 + 1틱 |
   | 캔들 | 현재봉 시가 (+전봉 양봉 확인 체크) | 진입 = 시가 − 3틱 |
   | 수동 | 진입가 직접 입력 | 익절/손절만 계산 |
3. **익절%(기본 2) / 손절%(기본 10) / 수량 입력 → [계산하기]**
   → 분할별 진입·익절·손절가가 **$와 ₩ 병기**로 표에 나옵니다.
4. **주문 버튼** (표의 각 줄마다):
   - **진입 지정가** — 그 가격에 매수 주문(당일 유효)
   - **OCO 익절/손절** — 보유 중일 때. 익절가·손절가 동시 감시, 한쪽 발동 시 다른쪽 자동 취소
   - **OTO 진입→익절** — 진입 체결되면 익절 감시 시작(⚠ 손절 미포함 — 토스 스펙)
   - 누르면 **확인 팝업**(가격·수량·원화 총액)이 뜨고, 팝업의 버튼을 눌러야만 전송됩니다.
   - 💡 권장: **진입 지정가 → 체결 확인 → OCO 등록** 2단계.

## 4. 나머지 탭

- **주문 현황**: 미체결 일반 주문 + 등록된 조건주문 목록·취소. [새로고침]을 눌러야 갱신됩니다.
- **기록**: 이 도구가 한 일(주문·모의 전송·취소) 시간순 기록. 껐다 켜도 유지.
- **설정**: 연습/실서버 모드, 토스 API 키(이 컴퓨터의 앱 데이터 폴더에만 저장, 화면 재표시 없음).

## 5. 장(場)과 주문

- **데이·프리·본장 3개 장 모두 주문 가능**합니다(수동 도구라 장 제한 없음).
- 상단 배지에 현재 장이 표시됩니다. 마감 1분 전(정정·취소 불가 구간)에는 경고 배지가 뜹니다.
- 지정가+수량 주문은 장 구분 제약이 없습니다(금액 주문·소수점 매도만 정규장 전용 — 이 도구는 안 씀).

## 6. 안전장치

| 장치 | 내용 |
|------|------|
| 주문 잠금(드라이런) | 실서버 주문은 전부 모의 기록만. 소액 테스트 후 별도 해금 |
| 확인 팝업 | 모든 주문은 사람이 팝업에서 한 번 더 눌러야 전송 |
| 킬 스위치 | 켜면 모든 주문·취소 버튼 잠금(계산·조회는 가능) |
| 진입가 오타 검사 | 진입가가 현재가 ±15% 벗어나면 차단(자릿수 실수 방지) |
| OCO 규칙 검사 | "익절 감시가 > 현재가 > 손절 감시가" 아니면 전송 전 차단 |

## 7. 연습 모드

키 없이 앱 안의 가짜 토스 서버로 전 과정을 연습할 수 있습니다(실제 돈과 완전 무관).
연습 모드에서는 주문이 실제로 가짜 서버에 접수되어 조건주문 목록까지 볼 수 있고,
🎮 가격 조작 칸으로 현재가를 움직여 볼 수 있습니다.

# 카일봇 데스크톱 앱 사용법 (v0.1)

> 대상: 처음 쓰는 사람 기준. 용어는 괄호로 풀어서 설명합니다.

## 1. 이 앱은 무엇인가

- 카일봇을 **더블클릭으로 켜는 하나의 프로그램**으로 만든 것입니다(설계서 S5 단계).
- 터미널(명령어 창) 없이, 봇 켜기/끄기·매매 계획·기록 확인을 전부 화면에서 합니다.
- **v0.1 은 "드라이런 전용"입니다** — 실주문(진짜 돈으로 주문)이 코드 차원에서 잠겨 있어
  어떤 설정을 해도 실제 주문은 절대 나가지 않습니다.
  (이유: 토스 주문 API 필수 항목 확정이 아직 안 끝남. progress.md 남은 일 1번)

## 2. 설치

1. `release/KyleBot-0.1.0-arm64.dmg` 파일을 더블클릭
2. 열린 창에서 **KyleBot 아이콘을 Applications(응용 프로그램) 폴더로 드래그**
3. 런치패드(또는 응용 프로그램 폴더)에서 **카일봇** 실행
   - 처음 열 때 macOS 가 "확인되지 않은 개발자" 경고를 띄우면:
     앱 아이콘 **우클릭 → 열기 → 열기** (애플 개발자 인증서 없이 만든 개인용 앱이라 그렇습니다)

## 3. 두 가지 모드

| 모드 | 무엇인가 | 키 필요? | 돈 관련 위험 |
|------|----------|---------|--------------|
| **연습 모드** (기본) | 앱 안의 "가짜 토스 서버"에 붙어 도는 시뮬레이션 | 불필요 | 전혀 없음 |
| **실서버 모드** | 실제 토스 서버에서 시세·잔고를 **읽기만** 함 | 필요 | 없음(실주문 잠금) |

## 4. 연습 모드로 한 판 돌려보기 (5분)

1. 오른쪽 위 **▶ 봇 시작** 클릭 → 로그에 "가짜 토스 서버 시작"이 뜸
2. "새 매매 계획"에서 종목(AAPL) 확인 후 **시세 불러오기** 클릭
   → 진입/익절/손절 가격이 자동 계산됨(진입 −0.5% / 익절 +2% / 손절 −10%)
3. **이 계획으로 세션 시작** 클릭 → "매매 세션"에 진입 대기로 등록됨
4. 🎮 연습 가격 조작 칸에 **진입가보다 낮은 가격**을 넣고 "가격 변경"
   → 몇 초 뒤 "진입 체결 → 익절 등록" 로그
5. 이번엔 **익절가보다 높은 가격**으로 변경
   → "청산 take_profit" 로그 + **매매일지**에 손익 기록 ✅

## 5. 실서버 모드 (읽기 전용)

1. **설정 탭** → "실서버 모드" 선택
2. 토스 API 키(Client ID/Secret)와 계좌 번호 입력 → **설정 저장**
   - 키는 이 컴퓨터의 앱 데이터 폴더(`~/Library/Application Support/KyleBot/.env`,
     본인 계정만 읽기 가능)에만 저장됩니다. 화면·로그에 다시 표시되지 않습니다.
3. 대시보드로 돌아와 **▶ 봇 시작** → 실제 시세·잔고를 읽어 옵니다.
4. 세션을 만들면 안전장치 게이트까지 통과한 뒤 **"[드라이런] 진입 예정(실주문 안 냄)"**
   로그만 남습니다. 이것이 정상이며, 실주문은 다음 버전에서 해금됩니다.

## 6. 안전장치 요약

- **킬 스위치**(오른쪽 위 빨간 버튼): 누르면 신규 진입 전면 차단. 청산(위험 줄이기)은 허용.
- 일일 손실 한도 −3% / 연속 손절 3회 / 하루 주문 20건 / 세션당 $1,000 / 가격 이상 ±5%
  (전부 제안값 — 실운용 전 오너가 확정 필요, `lib/risk.ts`)
- 매매 기록은 앱 데이터 폴더 `kylebot-data.json`에 저장되어 껐다 켜도 유지됩니다.

## 7. 자주 묻는 것

- **앱을 끄면 봇도 꺼지나?** → 네. 창을 닫으면 봇도 정지합니다(안전한 기본값).
  백그라운드 상주(창 닫아도 계속)는 다음 버전 후보입니다.
- **윈도우 PC용은?** → 같은 코드로 `electron-builder --win` 빌드만 하면 됩니다(윈도우
  기기에서 빌드하는 것이 가장 간단). 다음 세션 후보.
- **연습 모드 시각이 왜 7/16 10:00 인가?** → 데이마켓이 아닌 시간에도 흐름을 볼 수 있게
  "데이마켓 한복판"으로 시각을 고정한 것입니다. 실서버 모드는 진짜 현재 시각을 씁니다.

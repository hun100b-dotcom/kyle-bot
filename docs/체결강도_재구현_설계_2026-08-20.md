# 체결강도·매매분석 재구현 — 정본 설계 (2026-08-20)

> **정본:** `docs/체결강도_분석_2026-07-24.html`(원래 기획). 사장님이 별도 구상을 추가로 안 주셨으므로 이 문서가 기준.
> **핵심:** 체결강도를 "숫자 하나"가 아니라 **가격과 겹쳐 보며 진입·익절 타점을 짚어 주는 신호**로 만든다.

## 지금과 무엇이 다른가

| | 현재(v0.11) | 재구현(목표) |
|---|---|---|
| 표시 | 강도 숫자 + 작은 꺾은선만 | **가격선 + 강도선 겹쳐보기**(다이버전스가 눈에 보임) |
| 신호 | 없음(사람이 숫자만 봄) | **바닥반전(진입)·정점꺾임(익절)·강세 다이버전스**를 앱이 자동 표시 |
| 국면 | 없음 | 고점경고/하락중/진입/보유/익절 5국면 배지 |
| 매매분석 | 승/패 평균 강도만 | "**강할 때 샀나**"를 실제 매매와 묶어 검증(진입 시 신호 유무 라벨) |
| 탭 | 체결강도·매매분석 2탭 | **1탭으로 통합**(①실시간 세기 ②내 매매 검증) |

## 신호의 수치 정의 (정본 3·5장 → 구현 규칙, lib/strength.ts 순수함수 + 테스트)

데이터: `StrengthSample[]`(각 샘플에 `tsMs·price·strength·nTicks·session` 이미 있음). null 강도(매수 일방)는 계산에서 제외.

1. **바닥반전(진입 신호) `detectBottomReversal`**
   - 최근 구간에서 강도가 **100 아래(매도 우세)**에 있다가, **연속 3틱(샘플) 상승 + 기울기 부호가 −→+로 전환**.
   - = "던지는 힘 소진 + 능동 매수 유입 시작". → 삼분할 진입 근거.
2. **강세 다이버전스 `detectBullishDivergence`**
   - **가격은 직전 저점보다 더 낮은 신저점**인데 **강도는 그때보다 높게** 형성.
   - = "가격은 더 빠졌는데 파는 힘은 약해짐". → 2·3분할 진입의 강한 근거(별도 배지).
3. **정점꺾임(익절 신호) `detectPeakRollover`**
   - 강도가 **100 위**에서 정점을 찍고 **연속 3틱 하락 + 기울기 부호가 +→−로 전환**.
   - = "사 올리는 힘이 식음". → 익절 근거(특히 +2% 목표와 겹치면 신뢰↑).
4. **국면 판정 `phaseOf`** (정본 3장 표):
   - 강도<100 & 아직 반전 없음 → `하락중`(대기) / 바닥반전 or 다이버전스 → `진입`
   - 강도>100 상승 → `보유` / 정점꺾임 → `익절` / 그 외 100 위 꺾임 시작 → `고점경고`

**신뢰도·정직성(정본 4·6장):** 항상 "추정치" 표기. `nTicks`(표본)·제로틱 비중이 낮으면 "표본 얇음" 경고. 절댓값(150이면 매수 등) 금지 — **변화·전환**만 신호로. "단독 매매 금지 — 가격·거래량·캔들과 병행" 문구 상시 노출.

## 화면 (통합 "체결강도" 탭)

**① 실시간 세기**
- 종목·간격 입력 + [기록 시작/정지](온디맨드, 자동루프 금지 — 카프리 원칙).
- **겹쳐보기 차트**(SVG, 의존성 0): 위=가격선, 아래=강도선(100 기준선). 신호 지점에 ▲(진입)·▼(익절) 마커, 다이버전스 구간 강조.
- 현재 국면 배지 + "추정치·보조지표" 안내.
- 표(시각·강도·매수/매도량·표본)는 접기.

**② 내 매매 검증(구 매매분석)**
- 카프리 주문 시 진입/청산 강도 자동 스냅샷(기존 유지) + **진입 순간 신호(바닥반전/다이버전스) 여부 라벨**.
- 요약: 수익 매매 vs 손실 매매의 진입 강도·신호유무 비교(정본 5-3 연구질문 ①②).
- "표본이 쌓일수록 신뢰↑" — 검증 전 규칙화 금지 원칙 명시.

## 구현 순서 (커밋 단위, 되돌리기 쉽게)
1. `lib/strength.ts`에 신호 4종 순수함수 + vitest(상승/하락/전환/다이버전스/표본얇음 경계).
2. 엔진: `getStrengthState`가 신호·국면을 함께 반환(계산은 순수함수 재사용).
3. UI: 겹쳐보기 차트 + 신호 마커 + 국면 배지. 매매분석을 체결강도 탭 하위 섹션으로 이동(탭 통폐합).
4. 매매 스냅샷에 진입 신호 라벨 추가.
5. 더블리뷰 → 타입체크·빌드·테스트 → ship.

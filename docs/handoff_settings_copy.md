## ⓐ 설정 탭 현재 항목 — 용도·사용여부 (재정비 판단 근거)

설정 탭(App.tsx `paneTab === "settings"`)은 여러 `<section className="card wide">`로 구성. 위→아래 순서:

| 순서 | 항목(h2/h3) | 용도 | 사용여부·비고 |
|---|---|---|---|
| 1 | 🎨 화면 표시 | 손익색 미국식/한국식 토글 | ✅ v0.14/0.16 신규. 유지 |
| 2 | ☁️ 매매 이력 동기화 | 매매이력 암호화 클라우드 업/다운(비번) | ✅ 사용(회사서 리포트). 유지 |
| 3 | 📱 폰에서 쓰기 | 집PC 릴레이+터널 QR | ✅ 사용(폰 연동). 유지 |
| 4 | 설정 > 모드 | mock(연습)/live(실서버) 표시 | ✅ 유지(상태 표시) |
| 5 | 설정 > 실주문 활성화 | LIVE_ORDERS 토글(🔒 기본) | ✅ 안전 핵심. 유지 |
| 6 | 설정 > 주문 편의·안전 옵션 | 가격가드·확인생략 등 체크박스 | ✅ 유지 |

| 11 | 🛠 고급·도구 기록(접힘) | journal 진단 로그 | ✅ v0.12 이동. 유지 |

**재정비 방향(제거 대상은 거의 없음 — 대부분 실사용):**
- **그룹화가 핵심.** 지금은 큰 "설정" 카드 하나에 모드·실주문·옵션·손익비·시드·키·키동기화가 다 뭉쳐 있고,
  그 밖에 화면표시·이력동기화·폰연동·기록이 흩어져 있어 위계가 약함. 제안 그룹:
  ① **거래 연결**(모드·토스 키·실주문 활성화) ② **주문 기본값**(손익비·시드·안전옵션)
  ③ **클라우드 동기화**(키 동기화 + 매매이력 동기화 — 둘 다 "동기화"라 한데 묶어 혼동 제거)
  ④ **화면**(손익색) ⑤ **폰 연동** ⑥ **고급/진단**(기록).
- **중복/혼동:** "매매 이력 동기화"(2)와 "키 클라우드 동기화"(10)가 둘 다 '동기화'라 사용자가 헷갈림 → ③으로 통합·라벨 구분.
- 실제 제거할 만한 죽은 항목은 없음(모두 기능 연결됨). "정돈=그룹·순서·라벨"에 집중.

## ⓑ 특히 어려운 문구·라벨 위치 (직관화 대상)

(App.tsx 기준. 검색어로 찾으면 됨)
- **전문용어 그대로 노출:** "EMA200", "이치모쿠 구름", "체결강도", "OCO/OTO", "틱룰", "하이킨아시", "드라이런",
  "accountSeq", "clientOrderId". → 괄호 풀이는 있으나 여전히 벽. 첫 등장에 한 줄 쉬운 설명 + 이후 축약.
- **계산기(오더 티켓)**: 기법 라벨 "삼분할 (EMA200)"·"호가창 (매수벽+1틱)"·"캔들 (시가−3틱)" — 초보에겐 암호.
  각 기법에 "무엇을 하는지" 한 줄 툴팁/부제 권장.
- **탐색(스크리너)** 상단 설명 문단(App.tsx의 `탐색 <span className="hint">` 아래 긴 `<p className="hint">`):
  ①~⑤ 조건이 전문용어 나열 → 단계별 쉬운 말 + 접기.
- **체결강도 탭** 안내(`체결강도 기록 (매수체결량 ÷ 매도체결량 × 100)`) 및 하단 "추정치·보조지표" 문구 — 유지하되
  "이게 왜 중요한가"를 한 줄로.
- **매매분석(v0.19)** 강/약 비교 주석·헤드라인 — 이미 쉬운 편이나 표본 부족 시 문구 점검.
- **리포트/주문현황** "실현손익·평가손익·당일손익", "미체결/체결·종료", "조건주문(익절+손절)" — 용어 풀이 보강.
- **드라이런/실주문** 배지·경고 문구는 안전 관련이라 **명확성 최우선**(약화 금지).
- 공통 원칙: "왜"를 한 줄로, 괄호 남발 줄이고, 버튼 라벨은 동사+대상("지금 받기", "폰 연결 켜기")로 유지.

## ⓒ 디자인 토큰·컴포넌트 규칙 (톤 맞추기용 — v0.17~0.19 리디자인)

`src/App.css` 상단 `:root`에 정의. **새 화면·문구 손질 시 이 토큰/클래스만 쓸 것(하드코딩 색 금지).**

**색(토큰):**
- 배경 4층: `--bg #0a0b0f`(최하단) / `--panel #15181f`(카드) / `--panel2 #1e222c`(입력·세그 트랙) / `--surface3 #272c39`(선택·떠오른 요소).
- 경계: `--border`(rgba .07, 은은) / `--border-strong`(rgba .13, 표 구분선·패널 seam).
- 글자: `--text #f3f5fa` / `--muted #99a1b3`.
- 손익(토글 대응): **`--profit`/`--loss`만 쓸 것**(절대 --green/--red 직접 X). `.pnl-up/.pnl-down` 또는 `pnlClass()` 사용.
  한국식 토글은 `:root[data-pnl="kr"]`에서 토큰만 스왑되므로, 토큰만 쓰면 자동으로 따라감.
- 강조/CTA: `--primary`(=파랑 #4c82fb). 경고/드라이런: `--amber`.

**형태:**
- 라운드: `--r-sm 12` / `--r-md 20`(기본 카드) / `--r-lg 24`(히어로) / `--r-pill 999`(알약).
- 엘리베이션: `--sh-card`/`--sh-float`/`--sh-hero` + `--edge-hi`(상단 안쪽 하이라이트=유리 느낌). 카드엔 `box-shadow: var(--sh-card), var(--edge-hi)`.
- 타이포: `--fs-hero 52`(총손익)/`--fs-display 40`/`--fs-title 22`(카드 제목)/`--fs-sub 17`/`--fs-body 15`/`--fs-cap 13`. 숫자엔 `font-variant-numeric: tabular-nums`.

**컴포넌트 클래스:**
- `.card`(둥근 떠있는 카드), `.hero`/`.report-hero`/`.str-now`(그라디언트 히어로 카드), `.pill-seg`·`.seg`·`.tech-seg`(알약 세그먼트: 버튼 `.on`이 surface3+그림자로 떠오름), `.tab`(알약 탭), `.insight-card`(파랑 틴트 인사이트), `.sum-card`/`.sw-col`(KPI 타일).

**불변 규칙(안전·반응형):**
- Safe-area: `env(safe-area-inset-*)`(노치·홈바) 유지. 터치타깃 ≥44px. iOS 자동확대 방지 입력 `font-size ≥16px`.
- 폰(≤820px) @media 블록에서만 모바일 조정. 데스크톱 2컬럼(`.panes.twocol`)은 넓은 화면(matchMedia 1024)만.
- **DRY_RUN·킬스위치·실주문 배지 가시성 최우선**(리디자인에 묻히면 안 됨).
- 모든 변경: 타입체크(web+app)·vitest·라이브 검증 후 `npm run ship`(폰+PC 동시). 더블리뷰 + docs/dual_review 아카이브.

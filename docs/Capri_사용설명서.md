# Capri 매매도구 사용설명서 (오너용)

> 이 앱은 **자동으로 매매하는 봇이 아닙니다.** 사람이 판단하고, 앱은 **계산**과 **주문 제출**을 도와줍니다.
> 버튼을 누르지 않으면 앱은 아무것도 하지 않습니다.

---

## 1. 화면 구성 — 4개 탭

### ① 계산기 탭 (가장 많이 쓰는 곳)

| 입력 항목 | 무슨 값인가 / 어디서 얻나 |
|-----------|--------------------------|
| **종목 코드** | 미국 티커 (예: `AAPL`, `BNAI`). 트레이딩뷰/토스에서 보는 그 코드 |
| **[시세·환율 조회] 버튼** | 누르면 현재가와 환율을 1회 가져옴 (자동 갱신 안 됨) |
| **매매기법 선택** | 삼분할 / 호가창 / 캔들 / 수동 중 하나 |
| **전봉 종가** (삼분할) | 트레이딩뷰 차트에서 직전 봉의 종가 |
| **EMA200** (삼분할) | 트레이딩뷰에 EMA200 지표를 띄우고 그 선의 현재 값 |
| **매수벽 가격** (호가창) | 토스 호가창에서 두꺼운 매수 물량이 쌓인 가격 |
| **현재봉 시가** (캔들) | 지금 진행 중인 봉의 시가 (+ "전봉 양봉" 체크 필요) |
| **진입가** (수동) | 직접 정한 매수 가격 |
| **익절 %** | 몇 % 오르면 팔지 (기본 2) |
| **손절 %** | 몇 % 떨어지면 손절할지 (기본 10) |
| **수량(주)** | 몇 주 살지 (1 이상 정수) |
| **[계산하기]** | 진입가·익절가·손절가를 표로 산출 |

> 💡 숫자 칸은 **소수점 자유롭게** 입력됩니다(예: `11.33`). 위아래 화살표(스피너)는 v0.2.6에서 제거했습니다.

### ② 주문 현황 탭
위에서부터 **① 보유 포지션·손익 → ② 최근 주문 근거 → ③ 미체결 일반주문 → ④ 조건주문(OCO)** 순서로 보입니다.
각 주문 줄에서 **취소**할 수 있고, [새로고침]을 눌러야 갱신됩니다.

#### 보유 포지션·손익 (v0.2.10 신규)
```
AAPL  0.065533주   +28.79%  (+$4.76)
기준가 $252.29 (토스 평균매입가) · 현재가 $324.93
익절까지 +2.10%p / 손절까지 -8.40%p
[근거] 삼분할 2분할 · 전봉종가 $12.3 / EMA200 $11.1 · 진입 $11.9 · 익절 $12.14(+2%) · 손절 $10.71(-10%) · 3주
```
- **손익 %** = (현재가 − 기준가) ÷ 기준가 × 100. **수익은 초록, 손실은 빨강**입니다.
- **기준가**는 ① 내가 주문할 때 앱이 기록한 진입가가 1순위, ② 기록이 없으면 토스 평균매입가를 씁니다. 화면에 어느 쪽인지 괄호로 표시됩니다.
- **익절/손절까지 %p** 는 "지금 가격"에서 목표까지 남은 거리입니다.
- **[30초마다 자동] 체크박스**를 켜면 이 카드만 30초마다 다시 조회합니다(기본은 꺼짐).
- 국내 종목(원화)은 `₩`로 표시되며 달러 환산을 하지 않습니다.

#### 최근 주문 근거 (v0.2.10 신규)
주문을 낼 때마다 **그 시점의 매매기법 근거**가 자동으로 저장돼 목록으로 쌓입니다.
> ⚠️ **v0.2.10부터 새로 내는 주문에만 근거가 남습니다.** 그 이전 주문은 근거 기록이 없어 "근거 없음"으로 표시됩니다(토스가 기법 정보를 돌려주지 않기 때문입니다).

### ③ 기록 탭
앱이 한 일(주문·모의기록·취소·설정변경)이 시간순으로 남습니다. 문제가 생기면 여기를 먼저 보세요.

### ④ 설정 탭
- **모드**: 연습(가짜 서버) / 실서버
- **실주문 활성화**: 🔒 꺼짐이면 주문이 안 나감(모의만) / 켜면 실제 주문
- **토스 API 키**: Client ID / Secret / 계좌번호(비워두면 자동 조회)

## 2. 기법별 계산 공식

| 기법 | 진입가 공식 | 익절가 | 손절가 |
|------|------------|--------|--------|
| **삼분할** | 전봉종가~EMA200 구간을 3등분<br>1분할 = 종가 − gap/3<br>2분할 = 종가 − gap×2/3<br>3분할 = EMA200<br>(gap = 종가 − EMA200) | 진입가 × (1 + 익절%/100) | 진입가 × (1 − 손절%/100) |
| **호가창** | 매수벽 + 1틱 | 〃 | 〃 |
| **캔들** | 현재봉 시가 − 3틱 | 〃 | 〃 |
| **수동** | 직접 입력한 값 | 〃 | 〃 |

- **틱(최소 호가 단위)**: $1 이상 = $0.01 / $1 미만 = $0.0001
- **가격 절삭**: $1 이상은 소수 2자리, $1 미만은 4자리에서 **버림**(토스가 거부하지 않게)
- **삼분할 주의**: 전봉 종가가 EMA200보다 **위**여야 성립합니다(아니면 "진입 필터 불성립" 안내)

## 3. 주문 2종 — 토스에서 실제로 어떻게 동작하나

| 버튼 | 토스에 나가는 것 | 동작 |
|------|-----------------|------|
| **진입 지정가** | 일반 지정가 매수 1건 | 그 가격 이하로 내려오면 체결. 당일(DAY) 유효, 미체결분은 장 마감 시 자동 취소 |
| **조건주문(익절+손절)** | 조건주문(OCO) 1건 | 익절가↑ 또는 손절가↓ 중 **먼저 닿는 쪽이 발동**되고 다른 쪽은 자동 취소. **감시는 토스 서버가 하므로 앱을 꺼도 작동** |

> 조건주문은 **주식을 이미 보유한 상태**에서 거는 겁니다. 순서: 진입 지정가로 매수 → 체결 확인 → 조건주문 등록.

## 4. 주문이 막힐 수 있는 경우 (기본 상태 기준)

> **기본 상태에서 앱은 오너의 주문을 임의로 막지 않습니다.**
> 예전에 있던 일일 손실한도·연속 손절컷·일일 주문수·세션 금액상한은 **v0.2.7에서 완전히 제거**했습니다.

### 항상 적용 (앱의 임의 제약이 아님)

| 조건 | 왜 막나 | 뜨는 메시지 | 해결 |
|------|---------|------------|------|
| **잔고 부족** | 어차피 토스가 거부할 주문이라 미리 알려줌 | "토스가 거부할 주문입니다(잔고 부족). 필요 $X / 가능 $Y" | 수량 줄이기 / 예수금 확인 |
| **킬 스위치** | 오너가 직접 누른 비상정지 | "킬 스위치가 켜져 있어…" | 버튼 다시 눌러 끄기 |
| **실주문 잠금** | 오너가 켜고 끄는 스위치(기본 꺼짐) | 팝업에 "모의 전송(기록만)" | 설정 탭에서 실주문 활성화 |
| **계좌 미설정** | 토스가 계좌 헤더를 요구 | "계좌가 설정되지 않았습니다" | 설정 탭 저장(보통 자동) |
| **현재가 확인 불가** | 가격을 모르면 계산·검증 불가 | "현재가를 확인할 수 없습니다" | 잠시 후 재시도 |
| **OCO 순서** | 토스가 요구하는 구조 | "익절 감시가 > 현재가 > 손절 감시가" | 보유 중, 현재가 사이로 |
| **삼분할 필터** | 기법 정의 자체(전봉종가 > EMA200) | "진입 필터 불성립" | 다른 종목/기법 |
| **입력 누락** | 계산에 필요한 값이 빔 | "전봉 종가와 EMA200을 입력하세요" | 빈칸 채우기 |
| **취소 동결** | 토스 제약(마감 1분 전) | "마감 1분 전 취소 불가" | 마감 후 |
| **토스 서버 거부** | 장시간외·틱 불일치 등 | 토스 메시지 그대로 | 메시지대로 조치 |

### 선택 기능 (기본 꺼짐 — 원할 때만 켜기)

| 기능 | 기본 | 설명 |
|------|------|------|
| **오입력 방지** | **꺼짐** | 켜면 현재가에서 크게 벗어난 가격을 막음. **한도(%)는 오너가 직접 입력** |
| **주문 확인 팝업 건너뛰기** | 꺼짐(팝업 표시) | 켜면 버튼 누르는 즉시 전송(오발주 위험 ↑) |

## 5. 실주문 켜는 법 / 킬 스위치 / 문제 대처

**실주문 켜기**: 설정 탭 → "실주문 활성화" 체크 → 경고 팝업 확인 → 상단이 **🔴 실주문 활성**으로 바뀜.
끄려면 체크 해제(즉시 잠금).

**킬 스위치**: 상단 버튼 → 확인 → **신규 주문 잠금 + 미체결·조건주문 전량 취소**.

**문제가 생기면**: ① 기록 탭에서 마지막 메시지 확인 → ② 위 안전장치 표에서 해당 조건 찾기 → ③ 그래도 모르면 킬 스위치로 정리 후 토스 앱에서 직접 확인.

## 6. 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 숫자가 입력이 안 됨 / 이상한 값이 들어감 | (v0.2.5 이하) 스피너 화살표·즉시 변환 버그 | **v0.2.6으로 업데이트** |
| "오입력 방지"로 주문 거부 | 설정에서 그 기능을 켜뒀고 한도를 넘음 | 설정 탭에서 끄거나 한도를 넓히기 |
| 시세 조회 실패 | 키·계좌 미저장, 종목코드 오타 | 설정 탭 저장 확인, 코드 확인 |
| 주문 현황이 안 뜸 | (v0.2.3 이하) 조건주문 조회 버그 | v0.2.4+ 로 업데이트 |
| 주문 눌러도 안 나감 | 실주문 활성화 OFF(기본) | 설정 탭에서 켜기 |
| 원화가 토스 앱과 다름 | 환율 조회 시점 차이(1분 갱신) | 정상. 원화는 참고용, 주문은 달러 기준 |

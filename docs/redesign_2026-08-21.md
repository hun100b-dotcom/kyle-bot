# Capri UI 전면 리디자인 시안 (2026-08-21) — "열면 완전 달라 보이게"

> 지난 업그레이드가 안 느껴진 이유: **색·간격 토큰만 바꿔 레이아웃 구조가 그대로**였다.
> 이번엔 **구조(레이아웃)+형태(카드/모서리/그림자)+위계(숫자 크기)**를 동시에 바꾼다.
> 방향: **토스/로빈후드식 소프트 다크** — 넉넉한 여백 + 크고 친근한 숫자 + 떠 있는 둥근 카드.

## 무엇이 달라지나 (before → after)

| 요소 | 지금(before) | 개편(after) |
|------|-------------|-------------|
| 배경 | 납작한 단색 `#0f1115` | **4단계 엘리베이션**(더 어두운 바탕 + 층진 표면) → 카드가 떠 보임 |
| 카드 | 1px 테두리·radius 12px·평평 | **radius 20~24px + 소프트 그림자 + 상단 하이라이트**(유리처럼 떠 있음) |

## 화면별 개편(핵심)
- **매매리포트:** 상단 **그라디언트 히어로 카드**(총손익 52px) + 승률/실현/평가 **KPI 3타일** + 종목별 **리스트 카드**(원형 티커 배지 + 우측 손익).
- **계산기(오더 티켓):** 방식=**알약 세그먼트**, 입력=**큰 숫자 타일**, 결과=**히어로 숫자 블록**, 삼분할 **가로 스택 바** 시각화, 하단 **고정 CTA + DRY_RUN 배지**.
- **체결강도:** **게이지 히어로**(매수/매도 힘 바) + area-fill 라인차트 카드 + 신호 **알림 카드 스택**.
- **주문현황:** 보유/주문 **알약 세그먼트** + 카드형 리스트 + 상태 **색 알약 배지**.

## 디자인 토큰(다크, 붙여넣기용 요지)
- 배경 4층: `--bg-base #0A0B0F` / `--surface-1 #12141A` / `--surface-2 #1A1D26` / `--surface-3 #242833`.
- 텍스트: `--text-1 #F4F6FB` / `--text-2 #A8B0BF` / `--text-3 #6B7280`.
- 강조/손익: `--accent #4C82FB`(CTA), `--profit`/`--loss`(기존 토큰 유지 → **손익색 토글 그대로 작동**).
- 라운드: 카드 20px, 히어로 24px, 알약 999px. 그림자: 카드/플로트/히어로 3단 + 상단 inset 하이라이트.
- 타이포: display 52 / hero 44 / h1 24 / h2 18 / body 16 / cap 13. 숫자 tabular-nums.

## 시그니처 무브 4개(첫눈에 다르게)
1. **그라디언트 히어로 카드**(리포트·계산기 상단, 52px 숫자).
2. **알약형 세그먼트 컨트롤**(모든 전환).
3. **떠 있는 둥근 카드 + 소프트 그림자**(1px 평평 카드 폐기).
4. **큰 라운드 숫자 타일 + 원형 티커 배지 + 색 알약 배지**.

## 반드시 유지
- Safe-area(노치·홈바), tabular-nums, 44px 터치타깃, **DRY_RUN 배지 상시 노출**(안전).
- **손익색 토글**(미국식/한국식) 그대로 — 토큰만 갈아끼우므로 리디자인과 무관하게 작동.
- 순수 CSS(gradient·box-shadow)만 — 폰(PWA)·PC(Electron) 동일 렌더, 라이브러리 0.

## 구현 순서(되돌리기 쉽게 커밋 단위)
1. 토큰(배경 4층·라운드·그림자·타이포) 교체 → 2. `.card`/`.hero`/알약 세그먼트 공통 → 3. 리포트 히어로(가장 극적) → 4. 계산기 → 5. 체결강도 → 6. 주문현황 → 7. 하단/상단 바.
각 단계 타입체크·빌드·라이브·ship.

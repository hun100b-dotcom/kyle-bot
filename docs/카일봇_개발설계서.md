# 카일봇(kyle-bot) 개발 설계서

> 이 문서는 kyle-bot 레포 내 **유일한 사양서**다. 모든 구현은 이 문서를 근거로 한다.

미국 주식 자동매매 봇. 실계좌를 다루므로 CATCH 등 다른 프로젝트와 완전히 격리한다.

## 설계 원칙
- 판단은 사람, 실행은 기계
- 키 없이 90%까지 (실주문 연결 전까지 최대한 완성)
- 드라이런(dry-run) 우선
- 달러 주문 고정
- 안전장치 우선

## 확정값
- Day장 = 토스 데이마켓(미국주식·달러)
- Day장 시각(서머 기준, KST): 09:30 탐색 / 10:30 1차 / 11:00 2차
- 삼분할·캔들 시드: 주문당 50%
- 호가창(데이마켓) 시드: 90%

## 미확정 (S1엔 불필요, 주석 TODO로 표기)
- split_fill_policy 기본 first_only
- 애프터마켓 매매 여부
- 겨울 상대시각 처리
- 매수벽 정량 기준
- 일일 손실 한도 / 연속 손절 컷 수치

## M1: 계산 엔진 (lib/calc.ts)

### 함수
- `calcSplit3(baseClose, ema200, tpPct, slPct)`
  - 전봉종가~EMA200 구간을 3등분한 1·2·3분할 진입가 + 각 익절/손절가
  - `baseClose <= ema200` 이면 에러 반환 (진입 필터 불성립: gap>0 아니면 거부)
  - gap = 전봉종가 − EMA200
  - 1분할 = 전봉종가 − gap/3
  - 2분할 = 전봉종가 − gap*2/3
  - 3분할 = EMA200
- `calcOrderbook(wallPrice, tick, tpPct, slPct)` → 진입 = 매수벽 + 1틱
- `calcCandle(barOpen, tick, tpPct, slPct)` → 진입 = 현재봉 시가 − 3틱 (전봉 양봉일 때만)
- `roundPrice(price)` → $1 이상: 소수 2자리 절삭 / $1 미만: 소수 4자리 절삭
- `getTick(price)` → $1 이상: 0.01 / $1 미만: 0.0001

### 공통
- 익절 = 진입 × (1 + tp_pct/100)
- 손절 = 진입 × (1 − sl_pct/100)

### 주의
- 부동소수점 오차 조심(0.1+0.2 !== 0.3). 정수(센트/1만분의1달러) 단위로 계산.
- 익절/손절가도 반드시 roundPrice를 거쳐야 한다(토스 안 맞으면 400 에러).
- 반페니($0.005) 틱은 2027-11 유예이므로 당분간 위 규칙 유지.

## M0 / M0-A: 세션 스케줄 (lib/session.ts)

서머타임을 하드코딩하지 말고 luxon으로 'America/New_York' 기준 계산 후 KST 변환.

### 함수
- `getSession(now)` → 'day'|'pre'|'regular'|'after'|'closed'
- `getDayMarketOpen(d)` → 그날 데이마켓 개장 시각 (서머 09:00 / 겨울 10:00 KST)
- `getScanTime(d)` → 개장 +30분
- `getFirstOrderTime(d)` → 개장 +90분
- `getSecondOrderTime(d)` → 개장 +120분
- `getCloseDeadline(d)` → 데이마켓 마감 15분 전 (청산 시작 데드라인)
- `isOrderFrozen(now)` → 마감 1분 전 정정·취소 불가 구간인지

### 토스 제약 (M0-A) — 반드시 반영
- 마감 10분 전 신규 주문은 예약으로 전환되어 다음 세션에서 체결됨
- 마감 1분 전은 정정·취소 불가(킬스위치도 안 먹음)
- 미체결 주문은 다음 세션으로 자동 이월됨 → 봇이 명시적으로 취소해야 함(자동취소 의존 금지)

### 세션 시간표 (M0, KST 서머/겨울)
| 세션 | 서머 | 겨울 |
|------|------|------|
| 데이마켓 | 09:00~17:00 | 10:00~18:00 |
| 프리마켓 | 17:00~22:30 | 18:00~23:30 |
| 정규장 | 22:30~05:00 | 23:30~06:00 |
| 애프터 | 05:00~08:50 | 06:00~09:50 |

서머타임 2026-03-08 시작 ~ 11월 초 종료. 주말·미국 휴장일 처리도 고려(주석 TODO 표기 가능).

## 검증 케이스 (vitest)

### calc
- `(2.20, 1.93)` → 1분할 2.11 / 2분할 2.02 / 3분할 1.93
- `(1.80, 1.93)` → 에러(필터 미충족)
- 익절 2%/손절 10%: 진입 2.11 → 익절 2.1522→2.15 / 손절 1.8990→1.89
- `calcOrderbook(1.85, 0.01)` → 진입 1.86
- `calcCandle(1.50, 0.01)` → 진입 1.47
- `roundPrice(0.73105)` → 0.7310 / `roundPrice(2.1522)` → 2.15
- `getTick(0.99)` → 0.0001 / `getTick(1.00)` → 0.01

### session
- 2026-07-16 10:00 KST → 'day'
- 2026-07-16 23:00 KST → 'regular'
- 2026-07-16 18:00 KST → 'pre'
- 2026-01-15(겨울) 데이마켓 개장 → 10:00 KST
- 2026-07-16(서머) 데이마켓 개장 → 09:00 KST
- 서머타임 전환일(2026-03-08) 전후로 개장 시각이 바뀌는지
